# Build

This directory contains assets used for the automated build process.

It should contain:

```
BepInEx-Unity.IL2CPP*.zip (desired version)
com.onehalf.suzerainunbound.cfg (a default config generated by the plugin)
README_PluginOnly.txt
README_WithModloader.txt
```

Set the version string in `build_release.ps1`:

```
$version = "1.x.x"
```

Running `build_release.ps1` will rebuild the DLL and package the releases.

```
SuzerainUnbound_v1.x.x_PluginOnly.zip
SuzerainUnbound_v1.x.x_WithModloader.zip
```

This is not relevant for most users.
