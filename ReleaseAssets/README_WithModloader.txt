Instructions:
Extract the contents of this zip directly into your main Suzerain directory (where Suzerain.exe is located).
Launch the game and wait 1-2 minutes on the first boot for BepInEx to initialize.

Asset mods:
BepInEx/plugins/SuzerainUnbound/AssetMods is where asset mods go. See the readme inside it for details. The loader is off by default.

UPGRADING FROM v1.7.1 OR EARLIER - PLEASE READ:
As of v1.8.0, DLLs are located in BepInEx/plugins/SuzerainUnbound. If an older install exists, delete these from BepInEx/plugins (NOT from the new SuzerainUnbound folder):
  SuzerainUnbound.dll
  DiscordRPC.dll
  Newtonsoft.Json.dll
Your config file and settings are not affected and will carry over.
