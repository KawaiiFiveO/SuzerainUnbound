This plugin includes:
Discord RPC C#, used under the MIT license.
Newtonsoft.Json, used under the MIT license.

Instructions:
Drop the whole SuzerainUnbound folder directly into your existing Suzerain/BepInEx/plugins folder.

Asset mods:
The SuzerainUnbound/AssetMods folder is where asset mods go. See the readme inside it for details. The loader is off by default.

UPGRADING FROM v1.7.1 OR EARLIER - PLEASE READ:
As of v1.8.0, DLLs are located in BepInEx/plugins/SuzerainUnbound. If an older install exists, delete these from BepInEx/plugins (NOT from the new SuzerainUnbound folder):
  SuzerainUnbound.dll
  DiscordRPC.dll
  Newtonsoft.Json.dll
Your config file and settings are not affected and will carry over.
