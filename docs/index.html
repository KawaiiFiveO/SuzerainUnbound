Included Patches

Each patch can be individually enabled or disabled in the configuration file. Cheat patches are disabled by default.

Skip Splash

Skips the Torpor Games intro logos on every launch.

Enabled by default
Fast Dialogue

Instantly displays all text and enables Dialogue Skip — hold a key (default: LeftCtrl) to rapidly advance dialogue, including unread lines that vanilla does not allow skipping.

Enabled by default
Run In Background

Prevents the game from pausing or throttling its framerate when Alt-Tabbed, improving stability. Audio can also be muted automatically on tab-out.

Enabled by default (muted)
Yes I'm Sure

Automatically skip all in-game/setup "Are you sure about your decisions?" prompts. Optionally, also skip all system prompts (exit/quit/main-menu/load-checkpoint).

Enabled by default (skip in-game)
Dota Camera Rebind

Allow map dragging with the Middle-Mouse Button. (Does not affect Right-Mouse.)

Enabled by default
Fix Camera Edge Pan

Prevents endless panning when the mouse is on a second monitor. Optionally, disable edge panning entirely.

Enabled by default (edge fix)
Torpor Mode Unlock

Suzerain forces Torpor Mode ON for new profiles, blocking manual saves. This patch allows it to be turned OFF so you can save your game normally.

Disabled by default
Force Achievements

Allows Steam achievements to be obtained regardless of whether Torpor Mode is active.

Disabled by default
Strange Counters

You can track your player stats!

Extras
⚠ Cheat Patches

Torpor Mode Unlock and Force Achievements are disabled by default. Enabling them may permanently alter your save files or Steam profile. Do not enable these unless you fully understand their effects.

Installation

Prerequisite

Begin with a clean, vanilla installation of Suzerain. This mod is not compatible with MelonLoader-based mods (such as "Suzerain Modding Kit").

  1. Visit the Releases page on GitHub and download the latest With Modloader release. It will be named something like: 
    SuzerainUnbound_v1.x.x_WithModloader.zip
  2. Extract the contents of the zip file directly into your main Suzerain directory — the folder containing Suzerain.exe.
  3. (Optional) To enable or disable specific patches, open the configuration file in a plain text editor (such as Notepad) and edit to taste: 
    Suzerain/BepInEx/config/com.onehalf.suzerainunbound.cfg
  4. Launch the game. On the first boot, wait 1–2 minutes for BepInEx to initialize. If everything is installed correctly, a second console window will appear alongside the game window.

After a Game Update

If Suzerain receives an update, Suzerain Unbound will stop working. The BepInEx/interop folder must be deleted before the game will launch again. The safest approach is to fully uninstall BepInEx (see below), then install a new "With Modloader" release once one is available.

Uninstalling

To temporarily disable BepInEx without uninstalling, rename the BepInEx folder to something else (e.g. zBepInEx). The mod loader will not run until you rename it back.

To disable only Suzerain Unbound, remove SuzerainUnbound.dll from the plugins folder:

Suzerain/BepInEx/plugins/SuzerainUnbound.dll

To fully revert to vanilla, delete the following items from your Suzerain directory, then re-verify files on Steam if needed:

BepInEx/            (folder)
dotnet/             (folder)
.doorstop_version
doorstop_config.ini
winhttp.dll

⚠ Version Requirement

This plugin requires BepInEx 6.0 (IL2CPP) Bleeding Edge, tested on build #764. It will not work on BepInEx 5.x. If you do not have existing mods and do not want to install BepInEx manually, use the "With Modloader" bundle instead — it includes everything pre-configured.

The correct BepInEx builds are available from the official build server. Make sure to download the Unity IL2CPP build for your operating system (e.g. BepInEx-Unity.IL2CPP-win-x64).

Development Setup
Expand
+

To contribute to Suzerain Unbound or build from source, you will need to link the project against your local Suzerain installation.

Prerequisites

  • Suzerain must be installed.
  • BepInEx 6.0 (IL2CPP) Bleeding Edge must be installed in the game directory (tested on build #764). Standard BepInEx 5.x will not work.
  • Launch the game at least once with BepInEx active to generate the BepInEx/interop assemblies. If a game update occurs, delete this folder to regenerate them, then re-link in the project.

Linking Your Game Files

  1. Clone the repository to your local machine.
  2. In the project root, find Directory.Build.props.example and make a copy renamed to Directory.Build.props.
  3. Open Directory.Build.props in a text editor and replace PATH_TO_YOUR_SUZERAIN_GAME_FOLDER with your actual installation path, e.g.:
    C:\Program Files (x86)\Steam\steamapps\common\Suzerain
  4. Open the solution in Visual Studio 2022 and compile. The build system will automatically locate your local game assemblies.

Known Issues

  • General Crashes Suzerain and BepInEx (Bleeding Edge) are known to be unstable; some patches may compound this. If you experience crashes, try disabling patches one at a time to isolate the cause.

⚠ After a Major Game Update

Suzerain Unbound will break if the game receives a major update. If the latest release is outdated, you must disable or uninstall BepInEx entirely to play vanilla Suzerain in the interim. Submit an issue report if a patch is broken — include log files from the Suzerain/BepInEx folder in your report.
